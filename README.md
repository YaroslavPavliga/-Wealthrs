# 📊 Повний посібник користувача Wealthrs

**Wealthrs** — це консольна система персонального фінансового менеджменту та предиктивного розподілу капіталу. Програма автоматизує облік грошових потоків, динамічно розраховує пропорції накопичень, відстежує дефіцити бюджету та інтегрується з офіційними банківськими API для актуалізації фінансового стану.

---

## 1. Архітектура даних та інфраструктура зберігання

Програма побудована на базі повністю автономного, локального JSON-сховища, що гарантує абсолютну конфіденційність ваших фінансових даних.
* **Локальний файл бази даних:** Усі транзакції та глобальні налаштування відсотків записуються у файл `wealth_data.json`.
* **Автоматична серіалізація:** Програма самостійно створює цей файл за його відсутності та автоматично перезаписує його у зручному для читання форматі (`WriteIndented = true`) під час будь-якої операції.
* **Захист від дублювання (Нормалізація):** Внутрішня архітектура використовує метод `NormalizeAndCompare`, який автоматично розпізнає та зводить до єдиного стандарту різні типи українських апострофів (`ʼ`, `’`, `'`) та ігнорує регістр символів. Це унеможливлює пошкодження або втрату бази даних через друкарські помилки.

---

## 2. Смарт-можливості та інтеграційні інструменти

### 🌐 Автоматична інтеграція з API Національного Банку України (НБУ)
При кожному запуску програми у фоновому режимі викликається метод `UpdateRates()`. 
* Програма відправляє HTTP-запит до серверів НБУ (`bank.gov.ua`) та зчитує офіційні поточні курси валют у форматі JSON.
* З отриманого масиву парсяться та оновлюються змінні актуального курсу для USD та EUR.
* **Для чого це потрібно:** Ці курси підтягуються в модуль фінансового календаря для автоматичної конвертації рекомендованих відрахувань у валютну подушку безпеки (відображається еквівалент 50/50 у доларах та євро).

## 3. Детальний огляд модулів та логіки їх роботи

### Модуль 1: Управління надходженнями (Income Management)
Усі доходи стандартизовано вносяться через цифрове меню, що виключає помилки ручного введення:
1. **Зарплата** — основний фіксований дохід.
2. **Інвестиції** — при виборі цього пункту система автоматично змінює запит з "Опис / Назва" на **"Код інвестиції"** (зручно для введення тікерів акцій чи назв ОВДП).
3. **Депозит** — відсотки за банківськими вкладами.
4. **Додатковий заробіток** — фріланс, разові підробітки.
5. **Повернення в подушку** — спеціальна категорія для внесення коштів, які повертаються до резервного фонду після попереднього запозичення.

### Модуль 2: Управління витратами (Expense Management)
* **Обов'язкові витрати:** Базові потреби (оренда, комуналка, їжа).
* **Необов'язкові витрати:** Розваги, спонтанні покупки.
* **Вилучення з подушки:** Пряма фіксація форс-мажорних витрат, які профінансовано з резерву.

> 💡 **Динамічні таблиці та Смарт-сортування:** > Програма автоматично підлаштовує ширину колонок у таблицях під найдовший текст опису у вашій базі. Для зручності аналізу, записи у звичайних категоріях сортуються хронологічно, а **Обов'язкові та Необов'язкові витрати — сортуються за спаданням суми**. Це дозволяє миттєво бачити "найважчі" статті витрат зверху списку.

### Модуль 3: Календарний розподіл надходжень та контроль дефіциту
Це математичне "серце" Wealthrs. Модуль групує транзакції за днями та послідовно розраховує фінансовий стан.

#### 🧮 Алгоритм щоденного розподілу:
1. Збираються доходи за день.
2. Від них віднімаються обов'язкові витрати цього дня.
3. Розраховується **Чистий залишок для розподілу**.
4. Якщо залишок позитивний, він автоматично ділиться на 4 фонди відповідно до заданих вами відсотків (Подушка безпеки, Інвестиції, Спонтанні покупки, Вільні гроші).

#### 🚨 Борговий трекер (Симуляція дефіциту):
* Якщо в якийсь день стається **обов'язкова витрата**, а доходу немає, програма реєструє **Дефіцит дня**.
* Система автоматично вважає, що ця сума була *запозичена* з вашої фінансової подушки.
* Наприкінці календарного звіту виводиться фінансовий статус. Якщо запозичень було більше, ніж ви повернули, програма підсвічує консоль **червоним кольором** і показує точний **Актуальний борг до повернення**. Якщо боргу немає, виводиться зелений статус "Ідеальний".

## 4. Практичні фінансові сценарії

### 📆 Сценарій А: Отримання доходу та його розподіл
* **Як діяти:** Внесіть суму прибутку через Меню 1. Після цього одразу перейдіть у **Меню 3 (Розподіл надходжень)**. 
* **Результат:** Програма вирахує обов'язкові платежі та розпише, яку чітку суму в гривнях вам потрібно відкласти на інвестиції, скільки можна витратити, а яку суму варто конвертувати у валюту для безпеки.

### ⚡ Сценарій Б: Бездохідний період (Життя в борг у себе)
* **Як діяти:** Вносьте обов'язкові витрати у дні, коли у вас немає надходжень. Зайдіть у **Меню 3**.
* **Результат:** Ви побачите жовті попередження *"⚠️ ДЕФІЦИТ ДНЯ!"*. Коли ви отримаєте наступний дохід, частину коштів заносьте через **Меню 1 -> Пункт 5 (Повернення в подушку)**, поки червоний індикатор боргу не зникне.

### ⚙️ Сценарій В: Зміна фінансової стратегії
* **Як діяти:** Перейдіть у **Меню 3 -> Пункт 2 (Зміна відсотка)**.
* **Результат:** Ви можете переналаштувати пропорції (наприклад, змінити `CushionPct` чи `InvestPct`). Нова матриця розподілу миттєво збережеться і застосується до всіх розрахунків чистих залишків.

### 🔍 Сценарій Г: Пошук за періодами (Ретроспектива)
* **Як діяти:** У будь-якому меню оберіть пункт **9. Календар**.
* **Результат:** * Введіть дату (наприклад, `15.05.2026`), щоб перемкнути весь інтерфейс на відображення інформації за відповідний місяць.
  * Введіть діапазон через дефіс (наприклад, `01.05.2026 - 14.05.2026`). Програма виконає зріз даних і згенерує зведену таблицю виключно за ці дні.

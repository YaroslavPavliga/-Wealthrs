# 💰 WealthRS — Персональний Фінансовий Менеджер

**WealthRS** — це консольний додаток на мові C# (.NET) для автоматизованого ведення особистого бюджету, контролю обов'язкових та необов'язкових витрат, а також інтелектуального управління фінансовою подушкою безпеки.

Проект оптимізований для локального запуску на комп'ютері через командний рядок (CMD).

---

## ✨ Основні можливості

- **📊 Календарний розподіл надходжень:** Система автоматично ділить чистий залишок доходу за вашими власними відсотками (Подушка безпеки, Інвестиції, Спонтанні покупки, Вільні гроші).
- **🛡️ Контроль дефіциту та боргів:** Якщо у бездохідний день фіксується обов'язкова витрата, додаток автоматично фінансує її з "Подушки безпеки" та веде точний облік актуального боргу перед нею.
- **📈 Роздільний облік витрат:** Зручні динамічні таблиці для обов'язкових та споживчих (необов'язкових) витрат із розумним сортуванням за сумою чи датою.
- **🔄 Актуальні курси валют:** Інтеграція з API Національного банку України для відображення еквіваленту фінансової подушки в USD та EUR.

## 💻 Інструкція із запуску на комп'ютері (через CMD)

### Крок 1. Встановлення .NET SDK
Для того, щоб ваш комп'ютер міг скомпілювати та запустити код, на ньому має бути встановлено середовище .NET:
1. Перейдіть на офіційний сайт Microsoft: [завантажити .NET SDK](https://dotnet.microsoft.com/download)
2. Завантажте та встановіть останню версію **.NET SDK** (рекомендовано версії 8.0 або 9.0) для вашої розрядності Windows (x64).

### Крок 2. Завантаження проекту з GitHub
На сторінці цього репозиторію натисніть зелену кнопку **Code** -> оберіть **Download ZIP**. Розпакуйте завантажений архів у будь-яку зручну папку на вашому комп'ютері.

### Крок 3. Запуск програми
1. Відкрийте командний рядок Windows (натисніть комбінацію клавіш `Win + R`, введіть `cmd` та натисніть Enter).
2. Перейдіть у папку `src`, де знаходиться файл проекту `Wealthrs.csproj`. Для цього скористайтеся командою `cd` та вкажіть ваш шлях:
```cmd
   cd "шлях\до\розпакованої\папки\src"

Запустіть програму командою:
   dotnet run
   
📂 Структура репозиторію
Проект структуровано згідно зі стандартами розробки .NET додатків:

src/ — папка з усім вихідним кодом програми.

program.cs — логіка консольного меню, навігації та взаємодії з користувачем.

FinanceManager.cs — ядро програми: розрахунки, фільтрація, АПІ курсу валют та логіка календаря.

Transactions.cs — модель даних для сутності транзакції.

Wealthrs.csproj — конфігураційний файл проекту .NET.

.gitignore — захищає репозиторій від завантаження локальної бази даних (wealth_data.json) та тимчасових папок компіляції (bin/, obj/).

🛠️ Технологічний стек
Мова програмування: C# (.NET Core)

База даних: JSON (локальний файловий тип для повної конфіденційності даних)

Форматування: System.Text.Json, CultureInfo (повна локалізація під український формат дат та грошових одиниць ₴)
